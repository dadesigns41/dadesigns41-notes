# 🧠 Pseudocode Keywords Reference

A practical reference for planning logic before writing code.

---

## 🟦 Program Structure

| Keyword | Purpose |
|--------|---------|
| START  | Marks the beginning of a process |
| END    | Marks the end of a process |
| BEGIN  | Starts a block of steps |
| STOP   | Immediately ends execution |

---

## 🟩 Input / Output

| Keyword | Purpose |
|--------|---------|
| INPUT   | Data received by the program or function |
| OUTPUT  | Data produced or displayed |
| DISPLAY | Show output to user |
| LOG     | Record a message (console, debug, info) |

---

## 🟨 Variables & Assignment

| Keyword  | Purpose |
|---------|---------|
| VARIABLE | Declare a value that can change |
| CONSTANT | Declare a value that must not change |
| SET      | Assign a value to a variable |
| ASSIGN  | Same as SET (used interchangeably) |

---

## 🟥 Control Flow (Decision Making)

| Keyword | Purpose |
|--------|---------|
| IF      | Execute code when condition is true |
| ELSE    | Execute code when IF is false |
| ELSE IF | Additional condition check |
| END IF  | Ends a conditional block |

---

## 🟪 Loops / Repetition

| Keyword  | Purpose |
|---------|---------|
| FOR      | Loop a fixed number of times |
| FOR EACH | Loop over items in a collection |
| WHILE   | Loop while condition is true |
| DO      | Execute block at least once |
| UNTIL   | Stop loop when condition becomes true |
| BREAK   | Exit loop early |
| CONTINUE | Skip to next loop iteration |

---

## 🟧 Functions & Execution

| Keyword | Purpose |
|--------|---------|
| FUNCTION | Define reusable logic |
| CALL     | Execute a function |
| RETURN   | Send value back from function |

---

## 🟫 Data Structures

| Keyword | Purpose |
|--------|---------|
| ARRAY   | Ordered collection |
| LIST    | Generic collection |
| OBJECT  | Grouped key-value data |
| ITEM    | Single element in a collection |
| PROPERTY | Attribute of an object |
| KEY     | Identifier in key-value pair |
| VALUE   | Data stored under a key |
| INDEX   | Position in a list or array |

---

## ⚖️ Logic & Comparison

| Keyword | Purpose |
|--------|---------|
| EQUALS       | Compare equality |
| NOT EQUAL   | Compare inequality |
| GREATER THAN | Compare values |
| LESS THAN   | Compare values |
| AND         | All conditions must be true |
| OR          | Any condition must be true |
| NOT         | Invert condition |

---

## 🧱 State & Operations

| Keyword | Purpose |
|--------|---------|
| FIND   | Search for an item |
| ADD    | Increase value or insert item |
| REMOVE | Delete item or subtract value |
| UPDATE | Modify existing data |
| CHECK  | Verify a condition |
| COUNT  | Track number of items |
| TOTAL  | Sum of values |

---

## 🧠 Planning & Correctness

| Keyword | Purpose |
|--------|---------|
| ASSUME        | Expected input or state |
| REQUIRE       | Condition that must be true before execution |
| ENSURE        | Condition guaranteed after execution |
| INVARIANT     | Condition that is always true |
| PRECONDITION  | Required state before function |
| POSTCONDITION | Expected state after function |
| EDGE CASE     | Unusual but valid scenario |
| ERROR         | Invalid or failed state |
| FAIL          | Abort due to unmet condition |

---

### 📝 Tip
Pseudocode has no official standard.  
Consistency and clarity matter more than strict syntax.
